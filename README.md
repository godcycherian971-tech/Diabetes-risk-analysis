# Early-Stage Diabetes & Risk Analysis

## Project Overview
An end-to-end data analytics project examining patient symptoms, demographic data, and risk indicators for early-stage diabetes detection.

## Tools & Technologies
* **SQL:** Data querying and patient classification
* **Python (Pandas, Seaborn):** Data cleaning and visualization
* **Tableau:** Interactive dashboard creation

## Key Findings
* Significant correlation observed between visual blurring and diabetes risk.
* Higher positive occurrence identified in patients aged over 40.
